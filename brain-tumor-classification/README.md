# Brain Tumor Classification using Decision Tree

## Deskripsi
Proyek ini merupakan implementasi metode **Machine Learning Decision Tree** untuk mengklasifikasikan citra tumor otak menggunakan dataset Brain Tumor.

## Dataset
Dataset yang digunakan adalah Brain Tumor Dataset yang berisi fitur statistik citra seperti:
- Mean
- Variance
- Standard Deviation
- Entropy
- Skewness
- Kurtosis
- Energy
- Homogeneity
- Correlation

Target klasifikasi:
- 0 : No Tumor
- 1 : Tumor

## Metode
Metode Machine Learning yang digunakan adalah **Decision Tree Classifier**.

Model dilatih menggunakan data training dan diuji menggunakan data testing untuk mengetahui performa klasifikasi.

## Hasil
Model Decision Tree menghasilkan performa yang baik dalam mengklasifikasikan citra tumor otak dengan tingkat akurasi sekitar **97%**.
